# Музыка и Песни — Николай Цветков

## Самый простой способ добавить песню

1. Положите MP3-файл в папку `music`.
2. Положите обложку JPG/PNG в `covers`.
3. Откройте `tracks.js`.
4. Скопируйте один объект трека и поменяйте:
   - `title` — название
   - `artist` — исполнитель
   - `year` — год
   - `type` — Single / EP / Album
   - `duration` — длительность
   - `file` — путь к MP3
   - `cover` — путь к обложке
5. Откройте `index.html` в браузере — сайт готов.

Кнопка «Добавить для прослушивания» позволяет временно открыть MP3 на своём устройстве,
но это НЕ публикует файл для других людей.

## Публикация бесплатно

Самый простой вариант — GitHub Pages или Cloudflare Pages.
Загрузите содержимое этой папки в репозиторий/проект и опубликуйте `index.html`.

После публикации добавление новой песни делается так же: MP3 + обложка + одна запись в `tracks.js`,
затем загрузить изменения.

## Важно

Это статический сайт. Он отлично подходит для публичного музыкального каталога,
но здесь нет личного кабинета администратора и серверной загрузки файлов.
Если понадобится кнопка «Загрузить песню» прямо на сайте с телефона,
можно сделать следующую версию с базой данных и хранилищем.
